# FM Prime — site de demonstração

Site institucional da FM Prime (Av. Caxangá, 2414 — Recife/PE), feito como peça de portfólio.

- Arquivo único `index.html`, sem dependências de build.
- Imagens embutidas em base64, então o site funciona sozinho.
- Fontes e GSAP vêm de CDN.

## Publicar no GitHub Pages

1. Settings > Pages
2. Source: Deploy from a branch
3. Branch: `main` / pasta `/ (root)`
4. Save. O endereço fica `https://siteforyouu.github.io/fmprime/`
